# Java JDBC Student Management System

A simple console-based Student Management System built using Java, MySQL and JDBC.

I built this project to get hands-on experience with JDBC and understand how a Java application communicates with a MySQL database.

## Technologies Used

- Java
- JDBC
- MySQL
- MySQL Connector/J
- VS Code
- Git & GitHub

## Features

The application supports basic CRUD operations:

1. Add Student
2. View All Students
3. Find Student by ID
4. Update Student
5. Delete Student
6. Exit

## Concepts Practiced

- JDBC database connectivity
- DriverManager and Connection
- Statement
- PreparedStatement
- ResultSet
- executeQuery()
- executeUpdate()
- DAO pattern
- Exception handling
- Java packages
- CRUD operations
- SQL queries
